# defdict-images

Ілюстрації для застосунку DefDict: портрети героїв (`heroes/`) і реалії світу (`realia/`), JPEG до ~200 КБ.
Роздаються через jsDelivr: `https://cdn.jsdelivr.net/gh/Leonif/defdict-images@<тег>/<шлях>`.
`manifest.json` - відповідність статті словника (лема) і файлу. Нова версія картинок = новий тег.
